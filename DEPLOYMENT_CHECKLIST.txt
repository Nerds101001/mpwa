Issue: Node.js not found
  → Contact Hostinger support
  → Ask: "Does my plan support Node.js?"
  → Or use hybrid deployment

Issue: Permission denied
  → chmod -R 755 .
  → chmod -R 777 storage credentials bootstrap/cache

Issue: Database connection failed
  → Check credentials in .env
  → Verify database exists in cPanel
  → Test: php artisan tinker → DB::connection()->getPdo();

Issue: 500 Internal Server Error
  → Check logs: tail -f storage/logs/laravel.log
  → Clear cache: php artisan optimize:clear
  → Check permissions

Issue: Node.js server won't start
  → Check logs: tail -f node.log
  → Check port: netstat -tulpn | grep 3100
  → Try different port in .env
